# Security Policy

## Offline Privacy First
DAYCRAFT operates entirely on the user's device. No personal information, study logs, workout history, or schedule data is transmitted across the internet.

## Supported Versions
Security fixes and critical patches are actively applied to the latest release:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Security Concern
If you identify any security issue, data leak vulnerability, or potential exploit (such as unsafe native storage access or unauthorized filesystem modification):

1. **Do not create a public issue**.
2. Submit a detailed report directly through GitHub Private Vulnerability Reporting or contact the maintainers.
3. Include clear reproduction steps, sample environment configurations, and the impacted code paths.

Maintainers will acknowledge receipt within 48 hours and work with you on a responsible disclosure and patch cycle.
